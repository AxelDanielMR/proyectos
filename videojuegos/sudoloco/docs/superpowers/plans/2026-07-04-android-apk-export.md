# Android APK Export Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build and export a production-ready Android APK that can be shared and installed on any Android device without requiring development tools.

**Architecture:** Use EAS Build (Expo's managed build service) to compile the app from the cloud. This handles signing, optimization, and APK generation without requiring local Android SDK setup. The output is a downloadable APK that users can sideload via `adb install` or install by opening the file on their device.

**Tech Stack:** EAS CLI, Expo SDK 54, React Native 0.81, Firebase (Auth + Firestore + RTDB)

### Task 1: Verify and Update app.json

**Files:**
- Modify: `app.json`

- [ ] **Step 1: Read current app.json**

```bash
cat app.json
```

Expected: See current Expo app configuration (name, slug, version, etc.)

- [ ] **Step 2: Update version and add Android config**

In `app.json`, ensure you have (update `app.json`):

```json
{
  "expo": {
    "name": "Sudoloco",
    "slug": "sudoloco",
    "version": "1.0.0",
    "orientation": "portrait",
    "icon": "./assets/icon.png",
    "userInterfaceStyle": "light",
    "splash": {
      "image": "./assets/splash.png",
      "resizeMode": "contain",
      "backgroundColor": "#ffffff"
    },
    "assetBundlePatterns": [
      "**/*"
    ],
    "ios": {
      "supportsTabletMode": true
    },
    "android": {
      "adaptiveIcon": {
        "foregroundImage": "./assets/adaptive-icon.png",
        "backgroundColor": "#ffffff"
      },
      "versionCode": 1,
      "package": "com.sudoloco.app"
    },
    "web": {
      "favicon": "./assets/favicon.png"
    },
    "plugins": [
      [
        "expo-build-properties",
        {
          "android": {
            "usesCleartextTraffic": true
          }
        }
      ]
    ]
  }
}
```

Key changes:
- `version`: semantic version (e.g., "1.0.0")
- `android.versionCode`: increment with each build (starts at 1)
- `android.package`: unique identifier (reverse domain notation)

If any are missing, Expo will warn but still build. You can add custom icons later.

### Task 4: Build APK for Android

**Files:**
- None (generated by EAS)

- [ ] **Step 1: Start the build**

```bash
eas build --platform android
```

When prompted, choose:
- Build type: `apk` (not `aab`)
- Build profile: `production`

- [ ] **Step 2: Monitor build progress**

The CLI will show a URL to monitor the build. You can also watch it from: https://expo.dev/builds

Expected: Build takes 5-15 minutes depending on Expo servers

- [ ] **Step 3: Wait for completion**

The CLI will output:
```
✓ Build finished
📱 Your build is ready!
Download: https://expo.dev/artifacts/<build-id>
```

Copy the download URL and download the APK.

- [ ] **Step 4: Verify APK file exists locally**

```bash
ls -lh sudoloco.apk && file sudoloco.apk
```

Expected: File size 50-150 MB, type: "Android Package"

- [ ] **Step 2: Create installation guide**

Create file `docs/guides/INSTALL-APK.md`:

```markdown
# Sudoloco Android Installation Guide

## What You Need

- **Android device** (Android 5.0+)
- **USB cable** (recommended) or **file transfer** (optional)
- **30-50 MB free storage**

## Installation Methods

### Method 1: Direct File Install (Easiest)

1. **Download the APK file**
   - Get `sudoloco.apk` from the link provided
   - Save it on your Android device or computer

2. **Transfer to Android (if on computer)**
   - Connect device via USB
   - Copy `sudoloco.apk` to device storage
   - Disconnect USB

3. **Install on Android**
   - Open File Manager on your device
   - Navigate to where you saved `sudoloco.apk`
   - Tap the file → Select "Install"
   - Grant permissions if prompted
   - Wait for installation to complete

4. **Launch**
   - Open "Sudoloco" from your app drawer
   - Grant location/camera permissions if asked

### Method 2: ADB Install (Requires Computer Setup)

If you have Android SDK tools installed:

```bash
# Connect device via USB and enable USB Debugging in Developer Options
adb install sudoloco.apk
```

### Method 3: Email or Cloud Share

1. Email yourself the APK link or file
2. Download it on your Android device via Gmail
3. Tap the downloaded file and install

## Troubleshooting

**"Installation blocked"**
- Go to Settings → Security → Enable "Unknown sources" or "Install unknown apps"
- Then try installing again

**"App won't start"**
- Ensure Android 5.0+ (check Settings → About → Android version)
- Clear app cache: Settings → Apps → Sudoloco → Storage → Clear Cache
- Uninstall and reinstall

**"Permission denied"**
- Grant app permissions when first launched
- Check Settings → Apps → Sudoloco → Permissions

**App crashes immediately**
- Try force-stopping: Settings → Apps → Sudoloco → Force Stop
- Reboot device
- Reinstall app

## What to Expect

- **First launch:** ~5-10 seconds (loading assets)
- **Data:** App uses Firebase (requires internet for backend)
- **Storage:** ~100-150 MB after first run (cached assets, saves)
- **Battery:** ~2-4% per hour of play

## Uninstall

- Long-press app icon → Uninstall
- Or: Settings → Apps → Sudoloco → Uninstall

## Getting Help

If you encounter issues:
1. Share the error message/screenshot
2. Note your Android version (Settings → About → Android version)
3. Describe what you were doing when it crashed
```
